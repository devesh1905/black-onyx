Design rules

  • Dark theme, min body text 16 px on screen, node labels 14 px, readable from the back of the room.
  • Colour is never the only signal: blocked nodes also get a ⛔ icon and the word BLOCKED; trust shown as a text tag.
  • No network: inline all JS/CSS/fonts (PyVis with inlined resources). Test with Wi-Fi off.
  • One primary action per screen (Run scenario). Defence toggle always visible.
  • Nothing slower than 300 ms to render after the event list arrives.
